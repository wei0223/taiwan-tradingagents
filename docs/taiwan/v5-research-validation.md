# V5 evidence and forecast validation

The existing daily `upgrade` exports `v5-review.json`, HTML registers, a PDF
summary, `research-observation.json` and `portability.json`. No paid LLM calls,
orders, backdated releases, or edits to prior editions are introduced.

## Official events

`event_status.inventory` distinguishes VERIFIED, MISSING_PUBLISHED,
NOT_YET_PUBLISHED, SOURCE_UNAVAILABLE and REVISION_UNRESOLVED. Missing originals
of known announcements are not unpublished. Analyst expected dates are not
official schedules. Index-exhaustion gaps stay source-scope gaps; ezSearch is not
the complete MOPS universe. Events retain identity, timestamp, category, reason
and model impact. Material gaps block complete current research; reviewed known
facts remain readable as PARTIAL. Downgrading an event to nonmaterial requires an
eligible original, bound SHA256, reviewer, locator, rationale and explicit model
dependencies. A caller flag is insufficient.

`periods.superseded_documents` invalidates a predecessor when an eligible,
company-matched correction original has distinct bytes and is known by cutoff.
Quarter conversion, source packets, parameters and TTM respect this invalidation.
Replacement numbers still require review and recomputation. Future corrections
do not invalidate historical selections. Reviewed Q2 EPS availability is separate
from unknown Q3 publication history.

## Three parameter dimensions

Completeness, forward predictive evidence and calibration are separate PASS/FAIL
dimensions. Historical anchors do not prove future accuracy. Source timestamps,
hashes, rationale/formula, alternate scenario values and one-driver EPS/parent
sensitivities are retained. If scenarios agree, a mechanical stress is explicitly
labeled; it is not independent research. Zero aggregation components are
accounting conventions, not observed zero depreciation. Base is not most likely.

Revenue MAE/sample counts stay current-revision diagnostics, when available;
missing history is unavailable, not zero error. Prospective EPS metrics stay
unavailable until comparable outcomes exist. Strategy split/horizon counts are
displayed; horizons overlap and are not independent samples. Existing fixed-rule
walk-forward and small-sample suppression rules remain.

## Version bridge

Supply `extension_input.revision_comparison.previous_forward` using the archived
`extension.research_plan.forward`, together with its prior inputs and hashes in
the package. `model_revision.compare` recomputes all matching scenario/quarter
inputs, replacing changed drivers in fixed alphabetical order. Revenue, gross
profit, expense, operating/pretax/net/NCI/parent profit, diluted numerator, shares
and EPS deltas must telescope. Attribution order is not unique causal attribution.
Unknown EPS-only inputs leave old EPS/change null; unknown monetary drivers block
the bridge. NCI formula changes require an explicit structural bridge.

For 3231 Q4, parent profit changes by 2,065,334,492.01 TWD. The old model additionally
excluded Q2 FX/fair-value gains from net nonoperating income; the new model carries
reported net nonoperating loss. This is a normalization assumption change, not
issuer restatement or proof of better accuracy. Future GDR/CB qualification is
not established by a reconciled share-number equation. Monthly revenue is not
independent proof of future shipment/ASP/product mix.

## Comparable valuation and logs

`v5_review.historical_pe` requires consecutive direct quarterly diluted EPS
originals known at each price boundary, byte-bound same-company sources and a
reviewed common-share/corporate-action basis. Raw price/date/value/hash must
match. Every rejected point retains price, EPS periods, boundary and reason.
Current captures/vendor PE never become verified history, fair exit PE or a
cross-company undervaluation rank.

`forecast_journal.register` append-only registers a validated existing legacy
release or conditional-model receipt paired with its exact original model. It
retains original issue time separately from actual registration time, is
idempotent and rejects tampering. It never creates a new forecast or claims daily
captures existed in the past. Each new daily report freezes a separate hash-bound
research observation; observation is not publication.

## Portable package

`delivery.audit_package` checks local files and HTML anchors, rejecting encoded
path escapes. Machine-specific paths in HTML fail. The final archive and manifest
are verified after generation. Tests copy a complete package into another folder
and repeat checks. External URL availability is not implied. Standalone HTML is
readable; reproducing calculations requires its relative evidence package.

## Remaining empirical work

Official event/version mappings, direct Q4 EPS, future shipment/ASP evidence,
instrument-recognition notes, independently justified multiples and future OOS
outcomes remain pending when unavailable. Software checks cannot create missing
originals or turn current backfills into historical knowledge.
