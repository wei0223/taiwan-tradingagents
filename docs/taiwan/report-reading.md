# 三分析師報告與閱讀驗收

`research upgrade` 與日常 Sponsor acceptance 共用同一個正式模板。
三位分析師正文直接展開，四項裁決、長期估值與短期交易分開；原件與計算在後方。
只剩原始機器稽核 JSON 收在可展開區，列印時不輸出這份巨大 JSON。
這些是呈現調整，不會重算或改動原封存預測。

## 分析師輸入

`--analysts` 可繼續接受原來三個角色各自的文字陣列。
缺裁決、分歧或條件時，報告會標示需要編輯審查，不能假裝研究已通過。
正式閱讀版建議使用以下結構；三個角色都採同一格式：

```json
{
  "schema_version": 2,
  "stock_id": "3017",
  "as_of": "2026-10-15",
  "fundamental": {
    "position": "當期獲利的判斷，引用 [F02]",
    "stronger_case": "哪個主張較強，以及為什麼",
    "disagreement": "證據支持到哪裡、尚未解決哪一項爭點",
    "evidence_change": "新增證據改變了哪些既有判斷；沒有新資料也要明說",
    "paragraphs": ["完整分析與可追溯證據 [F01][F02]"],
    "conditions": ["哪個新數值／公告會導致哪一項改判"]
  },
  "technical": {
    "position": "目前量價條件的判斷 [T01]",
    "stronger_case": "已通過與未通過條件的權重",
    "disagreement": "中期趨勢與短線確認的區別",
    "evidence_change": "行情最後日期與是否新增觀測 [M01]",
    "paragraphs": ["完整技術論述"],
    "conditions": ["重算固定規則，不能追認先前進場"]
  },
  "institutional": {
    "position": "不同完整窗口的判斷 [M01]",
    "stronger_case": "支持或限制哪一方的論點",
    "disagreement": "不同窗口與不同法人方向是否一致",
    "evidence_change": "有沒有新增法人資料",
    "paragraphs": ["缺日不補零；重疊視窗不是獨立樣本"],
    "conditions": ["新資料下可明確判斷的條件；研究條件不是回測優勢"]
  }
}
```

結構化輸入必須綁定相同公司、相同分析日，避免直接套用另一家公司論述。
模板不判斷文字是否屬實；財務仍使用原有來源、日期、版本與數值審查。
`reading-review.json` 的 `complete_structure` 只代表欄位齊全、引用能綁定，
不代表人工內容審查、瀏覽器視覺驗收或預測績效通過。

## 原件與引用

- `[F01]`、`[F02]` 明確綁定 `review-input.documents.q1`、`.q2`，不猜測其他文件。
- 文件 ID 也可直接寫成 `[document_id]`；來源 bytes、公司與 SHA256 必須一致。
- `[M01]` 指向本次行情／法人觀測及 `snapshot.json`。
- `[T01]` 指向 `review.json` 中固定短線檢核；不是合理價或已成交條件。
- 未綁定的引用顯示缺口，不能製造看似有效的跳轉。
- 已驗證原件另存 `documents/<sha256>.pdf`；其他原件以 `.txt` 保存原 bytes，
  不將下載網頁作為可執行 HTML。
- 原件的公布／上傳、捕獲時間、版本與頁碼定位在來源區保留。
  有原件不等於已滿足數字採用條件；未來公布或版本不符的資料仍由既有審查排除。

## 版面與驗收邊界

頁首分開列實際產生時間、資料分析日、行情最後觀測日；產生日期不冒充即時資料。
手機使用單欄正文，寬表格限制在可鍵盤聚焦、左右捲動的容器，
來源長雜湊可換行；不要讓整個頁面橫向溢出。
A4 列印樣式重複表頭，三分析師正文保持可見，機器 JSON 不列印。

每次變更至少核對：

1. 3017 的三位論述：有支持理由、有真正分歧、有能觀察的改判條件，
   並將已實現獲利、現金、低估與短線分開。
2. 本機引用及原件雜湊有效；新目錄不能覆寫已交付報告／封存。
3. 2330、3017、3231 用同一 upgrade 流程重跑，財務計算與原預測保持相同。
4. 實際桌面、390px 手機寬度及瀏覽器 A4 列印預覽；檢查遮擋、表格、跨頁及連結。

若工具禁止讀取本機瀏覽器頁面，須明列這三項瀏覽器視覺驗收未完成。
CSS／HTML 自動檢查不等於實機畫面驗證；由同資料生成的紙本 PDF 也不能冒充 HTML 列印預覽。
