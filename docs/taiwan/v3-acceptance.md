# 研究品質驗收：公告、估值、前瞻與交易

這份規格區分「功能能執行」與「研究證據足夠」。單元測試成功不代表公告完整、估值合理、預測校準或策略可獲利。

## 公告母集合

`knowledge.completeness` 現在呼叫 `announcement_coverage.reconcile`，解析有原始 bytes 與 SHA256 的 MOPS 全類別索引，按公司、日期、公告識別及原件 URL 計算差集。F22 月營收、E02／M31／F26–29 財報、資本變動與更正均納入；未分類重大事項必須人工檢視，不會因類別未知而消失。

完全相同的官方重複列保留在原回應，計算時去重；相同識別但內容衝突則拒收。版本更正須連結到較早、同公司、不同原件雜湊的前版，不能只勾選「已看過」。

四類狀態分開：

| 狀態 | 意義 |
|---|---|
| `source_uncovered` | 沒有可信索引或沒有聲明查詢窗口 |
| `index_exhaustion_unverified` | 有回應，但缺原始回應內的總筆數／掃盡證據 |
| `missing_document` | 母集合中有尚未核對的原件或更正銜接 |
| `verified_no_updates` | 指定窗口已證實完整，且該類沒有事件 |
| `reviewed_events` | 指定窗口已證實完整，所有已發現關鍵原件完成核對 |

人工 `reviewed` 或 `coverage_verified` 旗標不再足以通關。沒有服務端總筆數的現行 MOPS 回應仍保留封鎖狀態，不能把程式支援的驗證協定冒稱官方現已提供該欄位。`first_observed_at` 僅為這次捕獲，不代表首次公布。研究模式、精確 `cutoff_at`／`data_as_of` 及捕獲限制繼續生效；回顧診斷不能取得「最新完整研究」資格。

## PE 固定樣本與版本差異

`valuation_basis.sample` 固定起訖、正值與缺值規則、目前版本、來源及逐日樣本；保存樣本與定義指紋。來源報列 PE 仍明標價格調整及 EPS 分母未核實，不改名為 TTM 或 Forward PE。

`valuation_basis.compare` 核對兩版指紋與中位數，輸出新增／移除日期、共同日期修訂、定義差異及門檻提醒。中位數差異用固定順序的可重算分解：舊全樣本→舊共同日期→新共同日期→新全樣本。這是數學歸因，不是經濟因果。

`valuation.valuation_config` 指定 `start`／`end`；`previous_sample` 提供前版 receipt。相同輸入及設定會有相同樣本雜湊。`historical_ttm` 是獨立入口，僅接受同公司、同幣別、未調整價格與當時已捕獲的同口徑稀釋 TTM 分子／加權股數原件，不接受把現在回補資料當當年已知版本。

## 前瞻分級及股數

正式 `forward_scenarios` 保留未知欄位，完整列出營收、毛利、營益、稅前、稅率、歸母、分子及加權股數。缺件附阻塞原因、應取得的證據；未知公布日期不編造交付期限。

`per_share_reference` 必須綁定已審查的 issuer capital packet。歸母除目前已發行股數只叫「每股歸母商數」，不能寫成基本或稀釋 EPS。95%／100%／105% 股數僅是明示敏感度軸，不是股數信賴區間。季內股數由既有日曆加權模型計算，授權、登記、掛牌均不自動視為認列。

`capital_model.evaluate_dilution` 依繼續營業控制盈餘、增量股數及稅後分子調整排序，計算反稀釋排除；不是接受 caller 宣稱「稀釋性」就當會計結論。增量股數本身仍需 EPS 附註與時間權重證據。

可另提供 `illustrative_profit_scenarios`，回答明示成本、費用、稅負條件下的損益。它與正式前瞻及已封存預測分開。四季歸母合計除固定現股可作條件尺度，市值／條件歸母也可重算，但不是 NTM 稀釋 EPS、Forward PE 或合理價。

## 參數與敏感度

`parameter_register` 每項保存來源／頁碼、頻率、公布與捕獲時間、事實／假設／不可觀測及測量誤差。沒有誤差估計時為 null；不能填零製造精確感。

`sensitivity` 支援營收、毛利率、費用率、匯率暴露、稅率及股數的一次一項端點與明示聯合情境。端點與聯合依存假設必填；不自動當變數獨立，也不配置機率。順位依所選端點引起的歸母變化範圍，不是經驗方差貢獻。

`python -m tradingagents.research score-parameter --release 原檔 --actual 實績 --evaluated-at 帶時區時間 --output 新檔` 提供正式入口，拒絕覆寫原檔。`parameter_tracking.score` 另外比對版本化的已發布預測與同公司、同季、同指標／單位／口徑實績。已在模型前公布的實績不列事前績效；原 release 保持不變。真正校準仍需後續實績及初版原件。

## 交易與基本面

回放現在使用原始價檢查可成交條件。一價或無量不能假定買入，無法賣出的停損／到期退出需等待後續可觀測開盤，沒有後續資料則 pending。沒有官方當日漲跌停／豁免與委託簿證據，仍只能作回顧假想回放，不能宣稱實際可成交。

`strategy_evaluation` 以同股票不重疊交易去重，按所有公司共同日曆週分群；30 筆同週事件不是 30 個獨立樣本。週群數不足不給區間；足夠時的固定種子區塊重抽也只是描述性區間，不保證已去除所有時間依賴。

基本面篩選必須使用進場前已發佈、已捕獲的研究與先固定的規則；事後財報回補不符合。技術單獨、基本面單獨與合併策略分開；缺基本面再平衡母體或現金帳時，不偽造單獨策略績效。基準行情未提供時，超額報酬保留不可用，不能把同股票持有報酬誤稱市場 alpha。
