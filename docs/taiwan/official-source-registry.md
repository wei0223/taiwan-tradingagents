# 正式來源清單與版本快照

本功能為研究加入可持續追蹤的官方來源帳本，不宣稱單一查詢能涵蓋全 MOPS，也不把今日下載版本當作歷史初版。既有美股與 FinMind Provider 不變；此路徑不需要 Secret、LLM API 或交易帳戶。

## 分類及完整性的邊界

| 類別 | 官方查詢與鍵 | 成功證明 | 仍不能證明 |
| --- | --- | --- | --- |
| 財報／附註 | TWSE 電子文件，按公司、年度、季度、AI1/AIA | 清單→表單→指定 PDF 的 bytes、SHA256、捕獲時間 | 歷史公告事件對應版本、初版、附註數字已人工審查 |
| 月營收 | MOPS `ajax_t05st10_ifrs`，公司、年、月 | 公司抬頭、財務月、TWD 仟元及原始數值重算 | 未捕獲的初次公布版、歷次更正已窮盡 |
| 股本／登記 | MOPS `ajax_t05st03`、`ajax_t05st05` | 現股欄位與可觀察的變更月份清單 | 募資完成日、實發股數明細、自由流通股、季度稀釋加權股數 |
| 募資 | TWSE 年度公開說明書清單及對應 PDF | 指定查詢內可見檔案的下載鏈 | 全部股本事件、方案已完成、條款數字已核對；非 PDF 待審 |
| 更補正 | MOPS `ajax_t56sb31_q1`，市場、年度、季別 | 這份查詢回應的控制欄位與公司列 | 查無列不等於公司從未更正，也不等於原件未替換 |

公告快易查沿用原始查詢作交叉核對，屬精選索引；筆數一致或服務端總數都不能證明全 MOPS 完整。七筆舊事件尚需官方批次識別、檔名／語言、當時 bytes、公開及替換紀錄。相同檔名、事件順序或語言數量不能補足對應。

## 保存與變動

`SourceStore` 保存內容定址的 `blobs/`、`receipts/`、`snapshots/`；`pointers/` 只指向最新快照。每次清單保留前版 SHA256，原件和收據禁止覆寫。收據保存 URL、查詢參數、HTTP 狀態、捕獲時間、原始 bytes SHA256；公布時間未知時明列 null。HTML 所稱上傳時間也不會自動當作初次公開時間。

狀態區分初次觀察、未變、內容變動、來源不可用、範圍移出。內容變動不自動等於官方更正；清單不再列出也不自動等於刪除。來源失敗仍保留上次已核對版本。另存的 `offline_revalidation` 不增加新公開捕獲證據，查核時間仍引用實際收據時間。

403、429、UTF-8／Big5 的 HTTP-200 查詢過量或拒絕頁，均停止該主機本輪查詢，保存拒絕原文；不繞過限制。真實連線有節流、單輪 request/PDF 上限，無重新導向和重試。所有傳輸和時鐘可 mock。

## 執行

先提供明確的公司／市場、季度、語言、月份、募資年度計畫。未完成期間、重複公司或無效月份在連線前拒絕。`rolling_scope=true` 只更新來源範圍：最近三個完整月份、當年已結束季度（年初用前一年）、當年募資；未知或尚未公布的原件仍 pending。

```powershell
python -m tradingagents.research refresh-sources `
  --plan C:/research/active-plan.json `
  --archive-dir C:/research/official-source-ledger `
  --output-dir C:/research/runs/NEW-UNIQUE-TIME `
  --review-input-dir C:/research/review-inputs
```

所有輸出均用新目錄。`upgrade` 同時接收 `--official-source-store` 與 `--official-source-snapshot`，重算原始值、核對已審查財報雜湊，將該公司的完整帳本鏈放入可攜報告。資料時點不能晚於研究 cutoff。新文件只有檔案鏈通過時，不能直接升格為已審查數值；季度現金流仍由正式 review 規則驗證同版本差分。

## 兩項驗收獨立顯示

1. **當期指定事實可用性**：指定月營收、現股、既有財務審查數字及新原件雜湊分開。部分事實可用不等於完整研究通過；行情更新、全部股本事件及估值資格仍各自檢查。
2. **歷史回測可用性**：每個歷史決策日均需可證明當時可得的原件版本。目前快照只從實際捕獲開始累積，`strict_pit_ready=false`。現今回補可作回顧診斷，不能回填成事前績效。

2026-10-21 實際驗收：三家公司七至九月營收與現股原件均可核對；2330、3017 的 Q1/Q2 檔案鏈與已審查文件相符。3231 文件下載收到 Big5 HTTP-200「查詢過量」頁，當輪新財報與募資版本 pending，保留先前已核對的財務事實。七筆歷史事件對應仍 0/7，未以新清單推斷結案。3017 現股更新為 392,670,107，只更新條件歸母商數參考，不改季度稀釋 EPS、歷史籌碼分母或已封存預測。

本機定期工作依實際執行時間另建目錄，保持已發布預測與舊來源不變；只有新原件、更正、重要來源變動或需處理錯誤時通知。它不會自動修改模型、合併 PR 或評分缺少實績的預測。
