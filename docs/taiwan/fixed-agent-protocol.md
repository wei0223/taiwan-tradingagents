# 固定 AI 研究與辯論協定 v1

模板位於tradingagents/research/prompts/v1：common加10個角色/階段檔。每個run保存協定、模板指紋、公司/截止日、輸入檔雜湊、依賴輸出雜湊、完整渲染Prompt、結果契約、實際回覆及執行收據。套件安裝也包含模板。

流程：planner先形成待驗證商業假說、關係企業/同業候選、財務傳導問題與來源清單；核對並匯入公司原件後agent-bind封存來源。基本面、技術面、籌碼面三份分析可與盲多空開場分開進行，開場不見三分析師或對方結論。兩份開場通過後才產生反駁，反駁回原Agent、逐項回覆對方claim；第三位新Agent做風險，最後協調者裁決。

固定的是研究步驟、欄位及驗收，不固定多空結論。基本面逐題回答planner的動態公司問題。會計獲利、現金持續性、估值、短期交易四項裁決分開；信心只為未校準質性描述。資料不夠可填unavailable，不能跳步標complete。

引文需定位至核對來源的純量，引用文字必須相符；技術面不能拿blocked計算包或舊公式補位。公司來源只用選定facts、EPS只用選定公開中位數。初始規劃候選不等於已查證關係或可比性。

預設新request加入agent_protocol並強制使用固定run。upgrade透過--agent-run驗證來源、公司快照、財務review與EPS未變，再取接受的分析及裁決；不允許重寫analysts、另替換debate或reader_research結論。完整run另存入報告證據包。舊報告/舊入口相容，不回寫既有封存。

Mock收據不能進正式run；Mock run不能進正式報告，測試報告須明選agent_report_mode=mock且首頁標示，永不宣稱獨立Agent已執行或績效。程式驗證格式、版本、引用及階段順序，不保證推論語意正確，也不能只靠使用者可填的agent_id/tool_call_id證明工具實際執行。協調者必須保存真實工具紀錄；盲Prompt的輸入清單是工作約束，不是檔案權限隔離。

新模板影響未完成run時要求另開新版；已接受輸入/原稿/收據不覆寫。全文操作見skills/taiwan-report/references/fixed-agents.md。此工作不派真實研究Agent、不取新行情、不用付費LLM、不新增監測或改舊預測。
